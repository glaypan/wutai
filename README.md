# 舞台流程表 (Stage Manager)

多角色实时舞台流程管理系统，支持局域网内多设备同步操作。

## 功能特性

- **三角色权限系统**：控制端（全权限）、助理端（备注/音乐/通道）、幕后端（仅备注）
- **实时同步**：WebSocket 多端实时同步，所有设备即时更新
- **跨平台**：浏览器访问，支持 iOS、iPad、Windows、macOS
- **Apple 风格界面**：Liquid Glass 设计，深色模式
- **PDF/Word 导入**：支持从文件导入节目列表
- **二维码访问**：扫码即可切换角色
- **桌面客户端**：Windows / macOS（Intel + M芯片）一键安装

## 方式一：Node.js 启动（推荐）

### 1. 安装 Node.js

- **Windows**：访问 https://nodejs.org 下载 LTS 版本安装
- **macOS**：`brew install node` 或从 https://nodejs.org 下载

### 2. 下载项目

```bash
git clone https://github.com/glaypan/wutai.git
cd wutai
```

### 3. 安装依赖

```bash
npm install
```

### 4. 启动服务器

```bash
npm start
```

### 5. 访问

启动后终端会显示局域网 IP 地址，例如：

```
╔══════════════════════════════════════════════════╗
║     舞台流程表服务已启动                            ║
╠══════════════════════════════════════════════════╣
║  本机访问:  http://localhost:3000                  ║
║  局域网IP:  http://192.168.1.100:3000              ║
╚══════════════════════════════════════════════════╝
```

- **本机**：浏览器打开 `http://localhost:3000`
- **其他设备**：浏览器打开 `http://<局域网IP>:3000`

## 方式二：桌面客户端（免安装 Node.js）

### 下载客户端

1. 用 Node.js 方式启动服务器（同上）
2. 浏览器打开页面，点击顶部 **⬇️ 下载客户端** 按钮
3. 选择对应系统下载：

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows | `stage-manager-win.bat` | 双击运行 |
| macOS Intel | `stage-manager-macos-intel.command` | 支持 macOS 10.14+ |
| macOS M芯片 | `stage-manager-macos-arm64.command` | Apple Silicon |

### 运行客户端

#### Windows
1. 下载 `stage-manager-win.bat`
2. 双击运行
3. 首次运行会自动下载 Node.js（如未安装）
4. 终端窗口显示 IP 地址后，保持窗口不关

#### macOS
1. 下载 `.command` 文件
2. **首次运行需右键 → 打开**（绕过 Gatekeeper）
3. 允许终端执行
4. 终端窗口显示 IP 地址后，保持窗口不关

### 其他设备连接

客户端运行后，终端会显示局域网 IP，例如 `http://192.168.1.100:3000`：
- 其他设备浏览器输入该地址即可访问
- 或点击页面顶部 **📱 二维码** 按钮扫码访问

## 三种角色说明

| 角色 | 网址参数 | 权限 |
|------|----------|------|
| 控制端 | `/?role=control` | 全部权限（增删节目、导航、重置、导入等） |
| 助理端 | `/?role=assistant` | 编辑备注、音乐、通道 |
| 幕后端 | `/?role=backstage` | 仅编辑备注 |

### 切换角色

- **方式一**：URL 参数 `http://IP:3000/?role=assistant`
- **方式二**：页面顶部点击 **⚙️ 齿轮图标** 选择角色
- **方式三**：点击 **📱 二维码** 按钮扫码切换

## 使用流程

### 1. 设置模式（控制端）

- 点击 **＋ 添加节目** 创建节目
- 填写节目名称、时长、备注、音乐节点
- 点击 **🎛️** 设置全局通道（话筒/线路）
- 拖拽节目可重新排序
- 点击 **📥** 可导入 PDF/Word 文件

### 2. 切换到演出模式

- 点击顶部 **⚙️ 设置模式** 按钮切换
- 演出模式显示：当前节目大卡片、下一节目预告
- 底部显示 **上一个 / GO / 下一个** 导航按钮

### 3. 演出操作

- **GO 按钮**：标记当前节目完成，自动跳到下一节目
- **上一个/下一个**：手动导航
- 每个节目右侧有 **↺ 重置** 图标，可单独重置
- 顶部 **↺** 按钮可重置全部节目

### 4. 其他设备查看

- 助理端和幕后端自动进入演出模式
- 可查看当前节目信息并编辑允许的字段
- 所有操作实时同步

## 常见问题

**Q: 其他设备无法访问？**
- 确认服务器和设备在同一局域网
- 检查防火墙是否放行 3000 端口
- 确认终端显示的 IP 地址正确

**Q: macOS 提示"无法验证开发者"？**
- 右键点击 `.command` 文件 → 选择「打开」→ 确认

**Q: 端口被占用？**
- 修改启动端口：`PORT=8080 npm start`

**Q: 数据保存在哪里？**
- 数据保存在服务器端的 `show.json` 文件中
- 桌面客户端保存在运行目录下
