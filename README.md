# 舞台流程表 v6.0.4

全平台、可离线运行的舞台节目流程与 Cue 管理系统。控制端启动服务器后，导演、助理、幕后和提示屏可通过局域网浏览器实时同步。

## v6.0.4 主要功能

- 彩排正计时、暂停/继续、结束保存，以及演出倒计时
- Cue 实时状态、下一 Cue 倒计时、自动/手动触发与状态重置
- 节目批量选择和删除，支持按角色授予“新增删除”权限
- 节目编辑器与全局设置共享话筒/线路类型
- PDF.js、Tesseract.js、中英文 OCR 模型完整内置，断网可用
- 桌面五组工具栏，手机四项底部导航和全屏操作抽屉
- Windows、macOS Intel/Apple Silicon、Linux、树莓派、OpenWrt、Android Termux 启动脚本

## 快速启动

要求 Node.js 16 或更高版本。下载 Release 安装包并完整解压，运行当前平台脚本：

| 平台 | 启动文件 |
| --- | --- |
| Windows | `启动-Windows.bat` |
| macOS Intel | `启动-macOS-Intel.command` |
| macOS Apple Silicon | `启动-macOS-ARM.command` |
| Linux / 树莓派 | `启动-Linux.sh` |
| OpenWrt | `启动-OpenWrt.sh` |
| Android Termux | `启动-Termux.sh` |

也可从源码启动：

```bash
git clone https://github.com/glaypan/wutai.git
cd wutai
npm start
```

启动后打开终端显示的控制端地址。其他设备连接同一局域网，再用控制端“连接与二维码”生成对应角色链接。

## 彩排与演出计时

1. 控制端打开“计时 / Cue”，开启“启用节目计时”。
2. 彩排时选择“彩排正计时”，点击“开始彩排”；结束后点击“结束并保存”。
3. 节目计划时长和彩排实测时长都以分钟填写，可用 `3.5` 等小数。
4. 演出时选择“演出倒计时”，可开启“演出优先用实测时长”。
5. GO 或切换节目后自动开始倒计时；未自动启动时使用“手动备用”按钮。
6. 倒计时到零后显示超时，不会擅自切换节目。

## Cue 状态

- `已触发`：本轮已经自动或手动触发
- `就绪`：已到触发时间，但当前处于手动模式或自动 Cue 已关闭
- `待触发`：尚未到触发时间，同时显示剩余秒数

计时器下方会显示下一个 Cue、所属轨道和剩余时间。“重置触发状态”用于重新彩排。

## 节目、权限和通道

- 设置模式中，有 `addDel` 权限的角色可全选并批量删除节目。
- 控制端默认拥有新增删除权限，导演、助理、幕后默认关闭，可在权限表中授权。
- 节目编辑器中的话筒/线路下拉框与全局通道类型同步。
- 从节目编辑器新增通道后，通道会写入全局配置并自动勾选到当前节目。

## 离线 PDF/OCR

导入弹窗会显示 `PDFJS_READY` 和 `OCR_READY`。两者就绪时，可断网导入 PDF 或图片并识别中英文。服务端 `/api/ocr-status` 可用于检查内置资源存在性和大小。

请通过启动脚本或 `npm start` 使用，不要直接双击单个 HTML；单文件打开无法提供服务端同步和完整 OCR 静态资源。

## 手机端

手机网页底部提供“节目 / 计时 / Cue / 设置”四个入口。编辑器和计时面板使用全屏抽屉，按钮触控区域不小于 44px，并支持 iPhone 安全区。

演出前建议关闭手机自动锁屏和低电量模式，并使用独立、稳定的现场路由器。

## 数据与安全

- `show.json`：节目和演出数据
- `show.json.bak`：自动备份
- `config.json`：端口、令牌和权限配置

发布包不包含这些现场数据文件。升级时先备份旧目录，再完整解压新版本；需要保留数据时，只迁移自己的 `show.json` 和 `config.json`。

系统面向可信局域网和离线演出环境。不要把服务端口直接映射到公网，也不要公开分享 `config.json` 或控制端令牌。
