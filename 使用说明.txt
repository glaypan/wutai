  舞台流程表 - 全平台稳定版使用说明
═══════════════════════════════════════════════════════

【适用环境】
  Windows 10/11 与可运行 Node.js 16 的旧版 Windows
  macOS 10.14.6 Mojave / Catalina 及更高版本（Intel 与 Apple Silicon）
  Linux、树莓派、OpenWrt、Android Termux
  iPhone / iPad、安卓手机和平板作为局域网客户端

【macOS Intel 首次启动】
  1. 解压整个 ZIP，不能只打开压缩包中的单个文件。
  2. 双击「启动-macOS-Intel.command」。
  3. 首次运行会校验并解压内置 Node.js 16.20.2，之后直接启动。
  4. 浏览器会自动打开带安全令牌的控制端链接。

  启动程序不会使用 sudo，不会写入 /usr/local，也不会修改系统 Node.js。
  如果 macOS 阻止首次打开，请在 Finder 中右键启动文件并选择“打开”。

【端口配置】
  在控制端右上角点击 🎹，进入“端口、密码与权限”：

  主服务 HTTP/WebSocket：默认 3000
  独立提示屏 HTTP/WebSocket：默认 3001
  OSC UDP：默认 5300

  三个端口都可自定义，保存后重启服务器生效。
  主服务端口和提示屏端口不能相同；OSC 使用 UDP，可以使用相同数字。
  设置页会同时显示“当前运行端口”和“下次启动配置端口”。
  当前运行端口来自实际监听 socket；配置端口来自 config.json。两者一致才表示本次进程已经使用新配置。

  如果两者不同，通常有两种原因：
  1. 刚保存了新端口，但服务器还没有重启。
  2. 启动环境设置了 PORT / DISPLAY_PORT / OSC_PORT / OSC_DISABLE，临时覆盖了 config.json。

  正常双击本包启动器时不会写死 3000，服务器会按真实监听端口自动打开控制端。
  如果电脑上同时运行旧版本（例如 43400/43401）和本版本（3000/3001），浏览器可能连到了旧进程。
  关闭旧终端后重新双击本包启动器，并以启动终端打印的控制端/提示屏链接为准。

【其他平台启动器】
  本目录同时提供以下启动脚本：

  Windows：启动-Windows.bat
  macOS Apple Silicon：启动-macOS-ARM.command
  Linux / 树莓派：启动-Linux.sh
  Android Termux：启动-Termux.sh
  OpenWrt：启动-OpenWrt.sh

  Windows、macOS ARM、Linux/树莓派启动器会优先使用系统已有 Node.js。
  如果没有可用 Node.js，会下载到本软件目录的 .runtime，不需要管理员权限，不写系统目录。
  Termux 版本会使用 pkg install nodejs-lts。

  控制端的“下载客户端”按钮会提供远程安装脚本。
  这些脚本会从当前服务器下载 stage-manager-core.zip / stage-manager-core.tar.gz，
  因此请从目标设备访问局域网控制端后再下载，对应 IP 和端口会自动写入脚本。

【提示屏与电脑视频输出】
  控制端点击 🖥️，可复制或直接打开独立提示屏链接。
  提示屏端口只接受只读连接，不能修改节目数据。

  使用 HDMI / DisplayPort 外接屏：
  1. 在“系统偏好设置 > 显示器”中使用扩展桌面。
  2. 点击“打开提示屏窗口”。
  3. 把窗口拖到外接显示器，再让浏览器进入全屏。

  网页无法直接选择物理 HDMI/DP 接口；由 macOS 决定窗口使用哪个显示输出。
  提示屏可显示当前/下一节目、状态、通道、音乐节点、备注、进度和字幕。
  提示屏设置还提供：实时、待机、黑场、冻结、测试图；断线时显示告警。
  “冻结”只冻结显示帧，不停止控制端节目状态；恢复实时后会立即追上当前状态。

【安全链接与二维码】
  控制端右上角点击 📱，可生成控制端、导演端、助理端、幕后端和提示屏链接。
  每个角色使用独立令牌。请只在可信局域网内分享，不要公开转发控制端链接。

【iPhone / iPad 使用】
  1. 服务器电脑与 iPhone/iPad 连接同一个 Wi-Fi；演出现场建议使用独立路由器，不依赖互联网。
  2. 在服务器控制端点击 📱，选择需要的角色并扫描二维码；也可在 Safari 输入“服务器 IP:主服务端口”。
  3. 使用密码连接时，点击页面连接状态，填写 IP:端口、角色和该角色密码。
  4. 常用客户端可在 Safari 分享菜单选择“添加到主屏幕”，以后像 App 一样全屏打开。
  5. 演出前把 iPhone“设置 > 显示与亮度 > 自动锁定”临时设为“永不”，并关闭低电量模式。

  iPhone/iPad 可使用节目导航、字幕、备注、通道、计时与提示屏等网页功能。
  iOS Safari 不支持 Web MIDI，因此不能作为 MIDI 桥；请在连接 MIDI 设备的服务器电脑上使用 Chrome/Edge 打开 MIDI 桥。
  手机更换 Wi-Fi、服务器电脑 IP 改变或端口修改后，应从控制端重新生成链接/二维码。

【密码链接】
  除二维码和 token 链接外，也可以在控制端右上角点击 🎹，进入“设置”，
  在“客户端密码链接”中为不同角色设置访问密码。
  其他客户端也可点击连接状态，分别填写 IP:端口、客户端角色和密码。
  客户端只保存服务器地址和角色，不保存明文密码。

  链接格式：
  控制/导演/助理/幕后：http://IP:主服务端口/?role=角色&password=密码
  提示屏：http://IP:提示屏端口/?role=screen&password=密码

  服务器验证密码后，会自动跳转到内部 token 链接。
  config.json 只保存密码哈希，不保存明文密码。
  但 password 会出现在 URL、浏览器历史和现场复制文本里，请只在可信局域网内使用。

【OSC】
  设置页提供 OSC 启用开关；保存后重启服务器生效。关闭时不会占用 UDP 端口。
  默认只监听本机 127.0.0.1，更适合与同一台 Mac 上的 QLab/OSC 软件连接。
  如需其他局域网设备发送 OSC，可在设置中勾选“允许局域网设备发送 OSC”。

  /stage/go       GO（完成当前并前进）
  /stage/next     下一个节目
  /stage/prev     上一个节目
  /stage/goto N   跳转到序号 N
  设置页的“允许局域网设备发送 OSC”默认关闭；开启后请同步放行系统防火墙 UDP 端口。

【MIDI】
  使用 Chrome/Edge 的 Web MIDI 功能。
  每个浏览器客户端有独立 MIDI 开关；关闭后立即断开设备并停止监听。
  可选择 MIDI 输入端口/设备、接收全部或指定 1-16 通道，并学习 Note、CC、PC 映射。
  MIDI 设备没有可填写的 TCP/UDP 数字端口；“MIDI 端口”指系统列出的输入设备。

  服务器 MIDI 桥：
  1. 在服务器电脑的 Chrome/Edge 打开控制端，点击 🎹 >“打开服务器 MIDI 桥”；也可使用启动终端打印的 MIDI 桥链接。
  2. 点击“连接设备”，允许浏览器访问本机 MIDI，并选择输入设备。
  3. 默认映射为 Note 60 = GO、Note 62 = 下一个、Note 58 = 上一个，可在 MIDI 设置中修改并限制通道。
  4. MIDI 桥通过已鉴权的主服务 WebSocket 工作，使用“主服务端口”，不另外占用一个 TCP/UDP 数字端口。

  Safari/Firefox 或非 localhost 的受限浏览器环境会明确显示不支持/权限失败。MIDI 桥应保持页面打开，浏览器或电脑休眠后需要重新连接。

【PDF 与 OCR】
  PDF.js、Tesseract.js、简体中文和英文识别模型均已内置，可离线导入。
  PDF 会先提取文字；文字过少时自动逐页 OCR。图片导入后需要点击“开始识别”。
  限制：PDF 最大 100 MB、500 页；图片最大 25 MB；DOCX 最大 50 MB。
  识别状态会显示页级进度，可随时点击“取消识别”；识别结果可在预览中编辑名称、时长和备注后再导入。
  自动拆分节目时，建议每个节目使用“1. 节目名”“2、节目名”或“19:30 节目名”格式；普通连续段落不会被擅自拆成多个节目。
  PDF 导出、FileSaver 和 DOCX Mammoth 解析库现在也随本包放在 vendor/，断网可用。
  如果页面显示“内置库未加载”，请确认没有只打开单个 HTML，而是通过服务器或完整安装包启动。

【时间轴与多轨 Cue】
  控制端点击顶栏 ≋，打开“时间轴与多轨 Cue”。
  内置音频、视频、字幕、OSC、MIDI 五条轨道，可启用/停用轨道、增加 Cue、编辑所属节目、开始延时（秒）、持续时长（秒）和执行内容，并可用 ▶ 手动试触发。

  字段含义：
  所属节目：该 Cue 使用哪个节目的开始时刻作为零点。
  开始延时：节目开始后多少秒触发；例如 3.5 表示 3.5 秒后触发。
  持续时长：字幕、音频或视频保持/播放多少秒；0 表示不自动停止。
  执行内容：字幕填文字；音频/视频填 /media/相对路径；OSC 填“/address value”；MIDI 填“note|cc|pc channel value”。

  音频 Cue 由控制端浏览器播放；视频和字幕 Cue 由独立提示屏播放。把文件放入 media/ 后再填写路径，现场使用前必须用实际控制电脑和提示屏完整试播。
  OSC/MIDI 轨道目前记录和广播指令状态；需要驱动 QLab、Resolume、DAW、灯光或 NDI/SDI/LTC 时，请在外部设备端完成对应映射。

【彩排正计时与演出倒计时】
  1. 在节目编辑器填写“节目时长（分钟）”；0 表示该节目不倒计时。
  2. 点击 ≋，打开“启用节目计时”，选择“彩排正计时”或“演出倒计时”。
  3. 彩排阶段进入演出模式后，当前节目从 00:00 正计时。可暂停/继续、归零；归零后点击“开始”重新计时。
  4. 彩排结束点击“保存实测”，实测秒数会写回当前节目；也可在节目编辑器手工填写“彩排实测时长（秒）”。
  5. 演出阶段按计划时长倒计时；开启“演出优先用实测时长”后，已保存实测的节目优先使用实测值。
  6. 开启“自动触发 Cue”后，Cue 会按当前节目的开始延时由服务器统一触发，每一轮只触发一次。归零或重新进入节目会开始新一轮。

  GO、上一个、下一个和直接选择节目都会重建当前节目的计时基准。无计划时长且无实测时长时显示“不计时”。

【节目与全局通道同步】
  顶栏 🎛️/通道按钮用于统一管理话筒和线路。每类只保留“类型 + 数量 + 添加”一套批量工具。
  在节目编辑器“启用通道”区域可直接“＋ 话筒”“＋ 线路”；新通道会加入全局配置并自动勾选到当前节目。
  删除全局通道前会确认，删除后会同步解除所有节目的该通道引用，避免残留无效通道。

【撤销、日志与工程包】
  控制端点击顶栏 ▣，可执行共享撤销/重做（服务端保留最近 50 个状态快照）、导出/导入 .stageproject 工程包和查看操作日志。
  导入工程包会校验 schema、版本和 20 MB 大小上限；工程包包含节目、通道、字幕、提示屏设置和时间轴。
  “锁定演出快捷键”会屏蔽空格、方向键、Delete、撤销/重做快捷键，触屏按钮仍可使用。

【数据与备份】
  演出数据：show.json
  自动备份：show.json.bak
  端口和令牌：config.json

  不要公开分享 config.json。复制整个软件文件夹即可迁移数据。
  服务端保存采用临时文件替换，并保留 .bak；启动时主文件损坏会自动回退备份。

【兼容性说明】
  Node.js 16 已停止官方安全维护，但它是兼容 macOS 10.14 的最后一代实用版本。
  浏览器端优先使用 Chrome/Edge；Safari/Firefox 不提供 Web MIDI。
  建议只在可信、隔离或离线的演出局域网中使用，不要把端口映射到公网。
