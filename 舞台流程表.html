🖥️ macOS
QLab (推荐)
  1. 打开 QLab，新建一个 Workspace
  2. 添加一个 Cue（任意类型）
  3. 在右侧 Inspector 中找到 Network 选项卡
  4. 设置 Host: 127.0.0.1（本机）或服务器 IP
  5. 设置 Port: 5300
  6. 设置 OSC Message: /stage/go
  7. 点击 GO 或按空格键触发
TouchOSC (iPad/iPhone)
  1. App Store 下载 TouchOSC（收费）或 MRGC Lite OSC Editor（免费）
  2. 打开 TouchOSC → Settings → OSC
  3. 设置 Host: 服务器局域网 IP（如 192.168.1.100）
  4. 设置 Port: 5300
  5. 编辑 Layout，给按钮设置 OSC 地址：/stage/go、/stage/next、/stage/prev
  6. 点击按钮即可控制
OSCulator
  1. 下载 OSCulator（https://osculator.net）
  2. 添加 OSC Event，设置地址为 /stage/go
  3. 在 Quick Config 中将目标设为 OSC → Host: 127.0.0.1 Port: 5300
  4. 可绑定 MIDI 设备、键盘快捷键、Wiimote 等触发
🪟 Windows
OSC Router / TouchOSC Bridge
  1. 安装 TouchOSC Bridge（免费，https://hexler.net/touchosc）或 OSC Router
  2. 配置发送目标 IP 为服务器 IP，端口 5300
  3. 设置 OSC 地址为 /stage/go 等
ableton Live / Reaper (MIDI)
  1. 在 DAW 中设置 MIDI 输出到虚拟 MIDI 端口（如 loopMIDI）
  2. 在浏览器 OSC/MIDI 设置中选择该虚拟 MIDI 端口
  3. 在 DAW 中映射键盘/控制器到对应 Note/CC
Python 发送 OSC (开发者)
pip install python-osc

from pythonosc.udp_client import SimpleUDPClient
client = SimpleUDPClient("127.0.0.1", 5300)
client.send_message("/stage/go", [])
client.send_message("/stage/goto", [3])  # 跳转第4个节目
📱 iOS / Android
TouchOSC (iOS/Android)
  1. App Store / Google Play 下载 TouchOSC
  2. 设置 → OSC → Host: 服务器 IP，Port: 5300
  3. 编辑布局，按钮地址设为 /stage/go 等
开源OSC (Android)
  1. Google Play 下载 OSC Controller 或 andOSC
  2. 设置目标 IP 和端口 5300
  3. 添加按钮，地址设为 /stage/go 等
🎹 MIDI 硬件设备
MIDI 键盘 / 脚踏板 / 控制器
  1. 用 USB 线连接 MIDI 设备到电脑
  2. 用 Chrome 或 Edge 打开舞台流程表控制端
  3. 点击顶栏 🎹 按钮打开 OSC/MIDI 设置
  4. 在「MIDI 输入设备」下拉框中选择你的设备
  5. 点击「🎯 学习」按钮，然后按下 MIDI 设备上的按键/踏板
  6. 系统自动识别 Note/CC/PC 类型并填入映射值
  7. 点击「💾 保存设置」
💡 支持: USB-MIDI 键盘、MIDI 脚踏板、AKAI LPD8、Korg nanoKONTROL、Behringer FCB1010 等
虚拟 MIDI 端口（软件桥接）
  • macOS: 安装 Audio MIDI Setup → 打开 MIDI Studio → IAC Driver（系统自带）
  • Windows: 安装 loopMIDI（免费）创建虚拟端口
  • Linux: 使用 a2jmidid 桥接 ALSA MIDI 到 JACK
💻 命令行测试
macOS / Linux (sendosc)
brew install sendosc   # macOS

sendosc 127.0.0.1 5300 /stage/go
sendosc 127.0.0.1 5300 /stage/next
sendosc 127.0.0.1 5300 /stage/prev
sendosc 127.0.0.1 5300 /stage/goto i 2
Node.js (osc-min)
npm install osc-min

const osc = require("osc-min");
const dgram = require("dgram");
const buf = osc.toBuffer({ address: "/stage/go", args: [] });
dgram.createSocket("udp4").send(buf, 5300, "127.0.0.1");
⚠️ 注意事项
  • OSC 需要服务器和发送端在同一局域网（或同一台机器）
  • OSC 默认端口 5300，可通过环境变量 OSC_PORT 修改，OSC_DISABLE=1 禁用
  • MIDI 仅在浏览器端运行（Chrome/Edge），Safari/Firefox 不支持 Web MIDI API
  • MIDI 设置保存在浏览器 localStorage 中，不同设备/浏览器需分别配置
  • 防火墙需放行 UDP 5300 端口（OSC）
