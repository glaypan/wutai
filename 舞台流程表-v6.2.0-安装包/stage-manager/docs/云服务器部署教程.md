# 云服务器部署教程（wutai 舞台流程表 v6.1.0）

适用：腾讯云/阿里云/华为云等 Linux 云服务器（Ubuntu/Debian/CentOS）

## 一、环境要求

- 系统：Ubuntu 20.04+ / Debian 11+ / CentOS 7+（64位 x86 或 ARM）
- 内存：≥512MB（推荐 1GB+）
- 带宽：≥1Mbps 上行（多人同时访问建议 5Mbps+）

## 二、安装 Node.js（二选一）

### 方式 A：系统包安装（推荐）

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证
node -v   # 应显示 v20.x
```

### 方式 B：无需安装（启动脚本自动下载）

项目自带 `启动-Linux.sh`，若系统无 Node 会自动下载内置 Node 20。

## 三、上传项目

```bash
# 1. 从 GitHub 下载发布包
wget https://github.com/glaypan/wutai/releases/download/wutai-v6.1.0/wutai-server.zip

# 2. 解压到 /opt/wutai
sudo mkdir -p /opt/wutai
sudo unzip wutai-server.zip -d /opt/wutai
cd /opt/wutai

# 3. 安装依赖
npm install

# 4. 配置（首次）
cp config.example.json config.json
# 编辑 config.json 修改端口/密码，见下方配置说明
```

## 四、配置 config.json

```json
{
  "entryPort": 18088,
  "port": 18089,
  "clientPort": 18090,
  "screenPort": 18091,
  "passwords": {
    "control": "你的控制端密码",
    "screen": "你的提示屏密码"
  },
  "rolePermissions": { ... }
}
```

端口说明：
| 端口 | 用途 |
|------|------|
| 18088 | 入口页（角色选择） |
| 18089 | 控制端（导演/控台） |
| 18090 | 客户端（助理/幕后） |
| 18091 | 提示屏（大屏显示） |

## 五、启动

```bash
# 前台启动（测试）
node server-standalone.js

# 后台运行（正式）
nohup node server-standalone.js > wutai.log 2>&1 &
```

## 六、systemd 常驻（推荐，开机自启 + 崩溃重启）

创建 `/etc/systemd/system/wutai.service`：

```ini
[Unit]
Description=Wutai Stage Manager
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/wutai
ExecStart=/usr/bin/node /opt/wutai/server-standalone.js
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
```

启用：

```bash
sudo systemctl daemon-reload
sudo systemctl enable wutai
sudo systemctl start wutai
sudo systemctl status wutai   # 查看状态
```

## 七、防火墙放行

```bash
# Ubuntu (ufw)
sudo ufw allow 18088/tcp
sudo ufw allow 18089/tcp
sudo ufw allow 18090/tcp
sudo ufw allow 18091/tcp

# CentOS (firewalld)
sudo firewall-cmd --permanent --add-port=18088-18091/tcp
sudo firewall-cmd --reload
```

> 云服务器还需要在**安全组**（控制台）放行 18088-18091 端口！

## 八、访问

- 入口页：`http://你的服务器IP:18088`
- 控制端：`http://你的服务器IP:18089`
- 客户端：`http://你的服务器IP:18090`
- 提示屏：`http://你的服务器IP:18091`

> 建议配置域名 + HTTPS（Nginx 反代），后续补充教程。

## 九、常见问题

| 问题 | 解决 |
|------|------|
| 外部访问不了 | 检查安全组 + ufw/firewalld 端口 |
| 提示屏 502 | 确认 18091 端口放行 + wutai 已启动 |
| npm install 失败 | 换国内源：`npm config set registry https://registry.npmmirror.com` |
| 端口被占用 | 改 config.json 端口后重启 |
