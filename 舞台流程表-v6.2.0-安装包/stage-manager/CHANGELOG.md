# wutai 舞台流程表 v6.2.0 更新说明

## 版本：6.2.0（2026-08-08）

### Tally 信号系统大幅增强

1. **自动 Tally**：开启后 GO 推进节目时，自动向目标角色发送下一节目 Tally 预告（无需手动点）
2. **实时 Tally 面板**：控制端/导演端右侧固定面板，实时显示所有活跃 Tally（节目/发送者/目标角色/自动或手动/剩余秒数），支持一键取消
3. **节目卡片闪烁**：接收端收到 Tally 时，对应节目在列表里闪烁 N 次（默认 4 次，可配）
4. **Tally 设置 UI**：设置弹窗新增 Tally 区块——自动启用/目标角色多选（助理/幕后/控台/导演）/GO 后延迟秒数/有效期/闪烁次数
5. **多角色目标**：一条 Tally 可同时发给多个角色（原仅单个 targetRole）

### HTTPS 与反向代理

- 新增 `docs/HTTPS与反向代理教程.md`：云服务器 Nginx + Let's Encrypt 方案 + 家庭 Caddy 自签方案 + WebSocket 注意事项
- Mac 本地已配置 Caddy HTTPS 反代（8443 端口，自签证书）：
  - `https://panloveli.top:8443/wutai/` → 18088 入口
  - `https://panloveli.top:8443/wutai-ctrl/` → 18089 控制端
  - `https://panloveli.top:8443/wutai-client/` → 18090 客户端
  - `https://panloveli.top:8443/wutai-screen/` → 18091 提示屏

### 其他

- 连接状态显示最后同步时间（"已连接 HH:MM:SS"）
- Tally 协议扩展：tally_list_request/snapshot、tally_cancel、tally_config_update/changed

### 兼容性

- 旧端（v6.1.0）仍可收到 tally_update/tally_acknowledge 消息，无缝兼容

# wutai 舞台流程表 v6.1.0 更新说明

## 版本：6.1.0（2026-08-08）

### 新增功能

1. **节目列表独立滚动**
   - 演出模式下节目列表成为独立滚动区域，拉动列表时右侧"正在进行/下一节目"提示卡片保持固定不动
   - 桌面端：列表 340px 侧栏 + 舞台区独立滚动

2. **手机端隐藏/显示列表按钮（悬浮）**
   - 各客户端（导演/助理/幕后/控制端）手机端新增右下角蓝色悬浮按钮
   - 点击切换节目列表显示/收起，文本随状态切换（📋 节目列表 ↔ ✕ 隐藏列表）
   - 手机端演出模式**列表默认收起**（只显示提示卡片），桌面端保持默认展开

3. **各客户端可切换控制端**
   - 修复"其他客户端无法切换到控制端"问题
   - 角色切换弹窗选"控制端"直接跳转控制端口（不再依赖 API 链接生成）

4. **提示屏（18091）修复**
   - 修复提示屏访问 502：服务端错误调用不存在的 `CLIENT_PORTAL_HTML_FN`（socket hang up）→ 改为 `CLIENT_PORTAL_HTML`，提示屏登录页正常返回

5. **端口监听修复**
   - 所有服务端口显式绑定 `0.0.0.0`（原默认绑定 IPv6 通配，局域网/公网 IPv4 无法访问）
   - 提示屏 18091 局域网/公网可访问

### 优化

- 节目列表拉出时提示卡片强制显示（min-height 保底，桌面 320px / 手机 260px）
- 手机端布局适配（底部导航安全区、悬浮按钮避开底栏）

### 部署

- 新增云服务器部署教程（见 `docs/云服务器部署教程.md`）
- 支持 Linux（含 ARM 架构）、macOS、OpenWrt

### 修复清单

| 问题 | 修复 |
|------|------|
| 拉节目列表时提示卡片消失/滚动 | 列表独立滚动 + 卡片保底高度 |
| 手机端无列表隐藏按钮 | 右下角悬浮按钮（z-index 高于底部导航） |
| 导演/助理/幕后无法切控制端 | switchRole 直接跳 18089 |
| 提示屏 18091 502 | 修复 CLIENT_PORTAL_HTML_FN 错误调用 |
| 端口 IPv4 访问不了 | 显式绑定 0.0.0.0 |
