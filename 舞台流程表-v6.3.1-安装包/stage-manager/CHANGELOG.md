# wutai 舞台流程表 v6.3.1 更新说明

## 版本：6.3.1（2026-08-08）

### 🎯 自动 Tally 触发修复（重要）

1. **修复节目单 Tally 预设不触发**：老数据节目缺少 `id` 字段，`maybeAutoTally` 因 `!next.id` 提前返回导致自动 Tally 永不触发。改为用节目下标做去重 key，老数据完全兼容
2. **修复去重误拦截**：去重 key 移后到确认触发后才记录，避免"先 GO 后加预设"被永久拦截
3. **角色字段校验**：`pc.roles` 增加 `Array.isArray` 校验（防止字符串误判）

### 📱 手机端体验优化（仅 ≤768px，不影响桌面）

4. **单屏舞台聚焦**：手机端节目列表变为左侧滑出抽屉（动画 + 遮罩），首屏只显示当前节目+计时+GO
5. **Tally 胶囊化**：手机端默认右上角「TALLY · N」计数胶囊，点击展开横幅列表；移动端横幅禁止拖动/缩放（避免误触）
6. **弹窗滚动锁定**：弹窗打开时锁定背景滚动（防穿透/跳动）
7. **底栏优化**：GO 大按钮加大热区（64px 高），隐藏冗余列表切换按钮

### 🏗️ 角色独立端口（v6.3.1 新增）

8. **导演端 18092 / 助理端 18093 / 幕后端 18094 / 控台端 18095**：各角色独立端口，登录认证隔离（错误角色拒绝），入口页选角色自动跳转
9. **保留 18090 兼容**：旧客户端地址继续可用

### 🔒 安全与文档

10. **教程脱敏**：云服务器/HTTPS 教程改为占位符（你的域名），不暴露实际外网地址
11. **端口文档更新**：README + 教程补全 8 端口表
