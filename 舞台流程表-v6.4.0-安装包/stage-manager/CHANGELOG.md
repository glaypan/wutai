# wutai 舞台流程表 v6.4.0 更新说明

## 版本：6.4.0（2026-08-09）

### 🏗️ 模板库（新增）

1. **内置模板**：婚礼典礼流程（9 节目）/ 公司年会流程 / 舞台演出流程（只读保护，归档拒绝 403）
2. **新建项目向导**：选类型（婚礼/年会/演出/空白）→ 选模板预览 → 命名创建，从模板深拷贝节目结构并记录 templateRef（模板更新不影响已建项目）
3. **模板管理**：项目中心新增"模板库"tab（列表/编辑/归档），归档过滤、归档后禁编辑
4. **另存为模板**：任意项目可保存为模板（排除运行时状态）
5. **安全存储**：原子写入（临时文件+rename）、schema 迁移、并发写串行化（serial 队列）、幽灵模板回滚、业务校验（name/duration）

### 🛡️ 防误触（新增）

6. **GO 长按 500ms** 触发（环形进度提示），STOP/清空确认后长按 700ms
7. **服务端幂等保护**：commandId + reservation token（跨角色共享、pending/done 状态、TTL 过期、容量淘汰防误伤）
8. **撤销增强**：关键操作执行前压入历史快照，失败自动释放幂等占用允许重试

### 🎨 UI 美化 + 图标

9. **SVG 图标系统**：6 个角色线性图标（控制/导演/助理/幕后/控台/提示屏），入口页替换 emoji
10. **设计令牌**：角色色（导演紫/助理蓝/幕后绿/控台橙/提示青）+ 状态色（active绿/completed灰/tally红）统一体系
11. **入口页重设计**：角色色顶线卡片 + 径向微光背景 + 悬停反馈，**修复角色独立端口跳转**（导演 18092/助理 18093/幕后 18094/控台 18095）
12. **主界面**：body[data-role] 角色色高亮 + 节目状态色条
